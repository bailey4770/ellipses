# Elliptical Orbits and Eclipses for Visual Learners (like me)

## What is an ellipse?

A technical definiton of ellipse is - for any point, P, on the ellipse, the sum
of distances to each focus is constant.

See labelled diagram for an ellipse to understand this visually.
![Labelled ellipse](./img/labelled_ellipse.png)

- `a` semi-major axis
- `b` semi-minor axis
- `c` distance from centre to focus
